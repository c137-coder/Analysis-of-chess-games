# Analysis of chess games

Локальное веб-приложение для разбора шахматных партий с настоящим движком Stockfish (NNUE), работающим прямо в браузере — без сервера и без интернета для самого анализа.

## Возможности

- Загрузка партий по нику chess.com или вставкой PGN
- Анализ движком Stockfish 16 (NNUE) с классификацией каждого хода: лучший / отличный / хороший / неточность / ошибка / зевок
- Определение дебютных ходов по открытой базе (lichess) — такие ходы не судятся движком
- Определение вынужденных ходов (единственный легальный ход)
- Понятные текстовые объяснения к каждому ходу: что конкретно происходит на доске и почему ход хорош или плох
- Озвучка комментариев (Web Speech API)
- Подписи игроков с автоопределением своей стороны

## Запуск

```
python3 nocache_server.py
```

и открыть `http://localhost:8791/index.html` в браузере.

## Стек

Ванильный JS, chess.js для правил, Stockfish (WASM) для анализа. Никаких сборщиков и зависимостей — всё нужное лежит в `vendor/`.
